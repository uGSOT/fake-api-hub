## Summary

The repo describes itself as "Open-source — built for learning and community contribution" in
`README.md`, but there is currently **no `LICENSE` file** in the repository. Without one, the
default is "all rights reserved," which contradicts the stated intent and creates ambiguity for
anyone who wants to reuse or contribute code.

## Why

An explicit license tells contributors and users what they're allowed to do with the code. This is
a prerequisite for the project to be genuinely open source.

## Acceptance Criteria

- [ ] Maintainer picks a license (MIT or Apache-2.0 are common defaults for this kind of project)
- [ ] Add a `LICENSE` file at the repo root with the full license text
- [ ] Add a `## License` section to `README.md` naming the chosen license and linking to the file
- [ ] Add license badges to `README.md` if desired (e.g. `![License](https://img.shields.io/badge/license-MIT-blue)`)

## Notes

This is a quick, low-risk issue — good for a first-time contributor to the project.
